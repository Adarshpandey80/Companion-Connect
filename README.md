# 🧑‍🤝‍🧑 Find Companion

Find Companion is a **MERN Stack** web application where users can hire companions for travel, shopping, events, and other activities. Individuals can create profiles, set their service rates, and connect securely through chat.

## 🚀 Features
- 👤 Companion Profiles
- 💰 Service Pricing
- 🔍 Search & Filter
- 💬 Real-time Chat(working)
- 📱 Responsive UI

## 🛠️ Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
